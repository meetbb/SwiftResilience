# SwiftResilience

Offline-first async networking and resilience infrastructure for modern Swift applications.

Mobile apps frequently fail under unreliable network conditions, leading to duplicate requests, inconsistent state, and poor user experience.
SwiftResilience provides a concurrency-safe retry and task orchestration layer built using modern Swift concurrency primitives.

✅ Planned Features
- Exponential retry policies
- Async task orchestration
- Cancellation-aware execution
- Offline request queue
- Request deduplication
- Actor-safe shared state
- Persistence layer
